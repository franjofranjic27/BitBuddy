# BitBuddy

BitBuddy 🌕 is an experimental crypto trading bot: Spring Boot microservices
(market data → decision → execution) communicating via Kafka, each with its
own PostgreSQL database, deployable to Kubernetes via Helm.

- **Source:** [github.com/franjofranjic27/BitBuddy](https://github.com/franjofranjic27/BitBuddy)
- **Setup:** see the [README](https://github.com/franjofranjic27/BitBuddy#quick-start)
